Installation

Comment installer l'application ?
  1. Sur le téléphone, ouvrez apps.urgences-rdc.com et touchez Télécharger. Préférez le Wi-Fi : le fichier fait environ 100 Mo.
  2. Touchez la notification « Téléchargement terminé », ou ouvrez Mes fichiers › Téléchargements › EB-Urgence.apk.
  3. Confirmez l'installation (voir les questions ci-dessous si Android vous bloque).
  4. Ouvrez EB Urgence, connectez-vous avec votre identifiant et votre code, puis acceptez toutes les autorisations.
Chrome dit que « ce type de fichier peut être dangereux »

C'est le message habituel pour une application installée en dehors du Play Store. Vérifiez que l'adresse est bien apps.urgences-rdc.com, puis choisissez Télécharger quand même.

Android demande d'autoriser cette source

Dans la fenêtre qui s'ouvre, touchez Paramètres, activez Autoriser cette source pour Chrome ou Mes fichiers, puis revenez en arrière et touchez Installer.

Play Protect affiche un avertissement

Play Protect ne connaît pas encore cette application, car elle ne vient pas du Play Store. Touchez Plus de détails › Installer quand même.

Samsung : l'installation est bloquée

Le Blocage automatique de Samsung interdit les applications hors Play Store. Désactivez-le le temps de l'installation : Paramètres › Sécurité et confidentialité › Blocage automatique, puis réactivez-le.

N'installez pas l'application dans le Dossier sécurisé : elle n'y recevrait ni les missions ni les appels.

« Application non installée »

Le plus souvent, une ancienne copie d'EB Urgence obtenue ailleurs (WhatsApp, Drive, clé USB) est déjà sur le téléphone. Désinstallez-la, puis recommencez avec le fichier de cette page.

Si le message persiste, le fichier est sans doute incomplet : voir la question suivante.

Le fichier ne s'ouvre pas ou semble abîmé

Le téléchargement s'est interrompu. Supprimez EB-Urgence.apk de vos téléchargements et recommencez, de préférence en Wi-Fi.

Mémoire insuffisante

Libérez au moins 500 Mo (photos, vidéos, applications inutilisées), puis recommencez.

Autorisations

Position : « Toujours autoriser »

La centrale voit ainsi votre unité même quand l'application est en arrière-plan ou l'écran éteint.

Si le choix n'apparaît pas : Paramètres › Applications › EB Urgence › Autorisations › Position › Toujours autoriser. Laissez aussi la position précise activée.

Notifications et affichage en plein écran

Indispensables pour être alerté d'une mission ou d'un appel quand le téléphone est verrouillé.

Paramètres › Applications › EB Urgence › Notifications : tout autoriser. Selon le modèle, activez aussi l'option « Notifications en plein écran ».

Micro et téléphone

Nécessaires pour parler avec la centrale pendant un appel. Acceptez-les à la première demande, ou dans Paramètres › Applications › EB Urgence › Autorisations.

Batterie : ne pas restreindre l'application

Sinon, Android peut l'endormir et vous ne recevez plus les missions.

  • Samsung : Paramètres › Applications › EB Urgence › Batterie › Non restreinte.
  • Tecno, Infinix, Itel : dans les réglages de l'application, autorisez le lancement automatique et l'exécution en arrière-plan (les noms varient selon la version).
  • Xiaomi, Redmi : économiseur de batterie sur « Aucune restriction » et démarrage automatique activé.

Mises à jour

Comment l'application se met-elle à jour ?

Toute seule. Quand vous l'ouvrez ou y revenez, elle télécharge discrètement les améliorations disponibles. Elles s'appliquent au prochain redémarrage : fermez complètement l'application, puis rouvrez-la.

Quand faut-il réinstaller ?

Seulement quand votre équipe annonce une nouvelle version complète. Téléchargez-la depuis la page d'accueil et installez-la par-dessus l'ancienne, sans désinstaller : vos données et votre connexion sont conservées.

Tant que ce n'est pas fait, l'ancienne version continue de fonctionner mais ne reçoit plus les mises à jour automatiques.

Quelle version ai-je ?

Ouvrez Profil et descendez en bas de l'écran. Vous y lisez par exemple « PROD · 1.0.2 · APK 1.0.2 (22) · OTA 01a1c577 » :

  • 1.0.2 : la version de l'application, à comparer avec celle de la page d'accueil ;
  • APK 1.0.2 (22) : le fichier installé ;
  • OTA… : la dernière mise à jour automatique reçue (« version d'origine » s'il n'y en a pas encore).

En service

Je ne reçois pas les missions quand l'application est fermée

Vérifiez dans l'ordre :

  1. le service est activé sur l'écran d'accueil (« Prêt pour intervention ») ;
  2. la position est sur Toujours autoriser ;
  3. les notifications sont autorisées ;
  4. la batterie n'est pas restreinte.

N'utilisez pas « Forcer l'arrêt » dans les paramètres : Android bloquerait alors toutes les alertes jusqu'à la prochaine ouverture.

« Reconnexion en cours… » s'affiche

La centrale n'a pas reçu votre position depuis un moment, par exemple juste après une installation ou une perte de réseau. Restez en service : le message disparaît seul en une à deux minutes, dès que la position repart.

S'il persiste, vérifiez que la localisation du téléphone est activée et que vous avez internet.

« Hors ligne » s'affiche

Le téléphone n'a plus internet : le suivi et les missions sont suspendus. Activez les données mobiles ou le Wi-Fi ; l'application se reconnecte seule.

Je n'entends pas les appels de la centrale

Vérifiez le volume de la sonnerie, que le mode « Ne pas déranger » est coupé, et que les notifications en plein écran et le micro sont autorisés.

Contacter le support

Dans l'application : Profil › Support & Bugs. Décrivez le problème ; votre version et votre modèle de téléphone sont joints automatiquement.

Si l'application ne s'ouvre pas, prévenez votre chef d'équipe ou la centrale.
