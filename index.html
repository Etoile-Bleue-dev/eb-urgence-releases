EB Urgence

Application des équipes d'urgence. Fichier d'environ 240 Mo : préférez le Wi-Fi.

Télécharger l'application

Installation

  1. Appuyez sur le bouton et attendez la fin du téléchargement.
  2. Ouvrez le fichier EB-Urgence.apk.
  3. Si Android le demande, autorisez l'installation depuis cette source.
  4. Ouvrez l'application, connectez-vous et acceptez toutes les autorisations.

Ensuite, l'application se met à jour toute seule.
